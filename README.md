# RoomView

中文、本地优先的轻量 2D / 3D 房间布局工具。输入房间与家具尺寸，在平面图中摆放，并用 3D 检查高度、门窗和空间关系。无需数据库、账号或模型 API Key。

支持自定义家具轮廓、曲线墙、选点测距、组合，以及 HTTP、浏览器、CLI 和 MCP 操作接口。参考 Room-Planner 的尺寸编辑与拖放交互，代码独立实现。

[环境与依赖要求](REQUIREMENTS.md) · [AI 接口说明](docs/AI_API.md) · [MIT 许可证](LICENSE)

## 启动

需要 **Node.js 22.12+**、npm 和现代浏览器。3D 需要 WebGL 2。完整环境要求见 [REQUIREMENTS.md](REQUIREMENTS.md)。

```sh
git clone https://github.com/redtree19/RoomView.git
cd RoomView
npm ci
npm run build
npm start
```

访问 **http://127.0.0.1:4317**。停止服务使用 `Ctrl+C`。

Windows 也可以直接双击 **Start-RoomView.cmd**；首次缺少依赖或构建时会自动准备，运行期间保留终端窗口。

开发时可使用热更新：

```sh
npm run dev
```

生产包只依赖本地静态文件，没有 CDN、在线字体或模型请求。`npm start` 使用 Node 内置 HTTP 服务，无需数据库。默认仅监听本机；用 `PORT` 更改端口。不要同时在同一端口启动开发和生产服务。

## 已实现

- **房间**：按尺寸创建矩形，拖绘矩形，逐点绘制多边形，精确编辑顶点，面积和层高；支持多个房间。
- **墙体**：直墙、二次贝塞尔曲线墙，可拖动起终点与控制点；可编辑厚度、高度、长度；曲线显示近似弧长。
- **门窗**：沿墙距离、宽度、底高、高度，真实 3D 开口。曲线墙的门窗按弧长定位。
- **家具**：床、沙发、桌椅、柜子、圆桌、地毯、绿植和通用方块。自定义宽、深、高、离地高度、颜色、角度；拖动、旋转、复制、锁定。
- **家具形状**：矩形、圆形／椭圆、L 形及任意简单凹多边形（3～80 个顶点）。家具库下方“逐点绘制异形家具”，Enter 闭合；选中后拖动白色顶点，或在“家具形状”中输入局部坐标、增删顶点。宽深修改会缩放轮廓，3D 按高度拉伸；支持保存、复制、组合和 AI 编辑。
- **2D 画布**：缩放平移、网格吸附、尺寸标注、对象列表与搜索。
- **多选与组合**：Ctrl/⌘ + 点击添加或移出选区；Ctrl+G 组合，Ctrl+Shift+G 逐层取消组合。支持嵌套组合、整体移动/旋转/复制/删除、保存与撤销重做。家具、房间、墙体和标注均可组合。
- **3D**：即时联动、轨道相机、俯视、完整墙高、随视角自动透明遮挡墙／实体墙／全部透明轮廓／隐藏墙、点选对象、PNG 导出。
- **选点测距**：M 后在画布点选起点与终点，显示直线距离、水平/垂直分量；优先吸附墙端点、房间顶点和家具角点；Alt 自由选点。测量不依赖家具 ID。
- **空间检查**：墙边净距、穿墙、家具重叠、越界、层高冲突。
- **保存**：自动保存 `data/project.json`，浏览器备份，撤销重做，JSON 导入导出，SVG 平面图导出。
- **AI**：稳定对象 ID、原子命令批次、dry-run、版本冲突保护，网页实时同步外部命令。

## 操作

| 动作 | 方法 |
|---|---|
| 曲线墙 | 点击起点 → 终点 → 控制点；选择后拖动白色控制柄 |
| 多边形房间 | 点击顶点，Enter 或点击起点闭合；Esc 取消 |
| 测距 | M，再点击两个位置；自动角点吸附，Alt 自由选点 |
| 多选 / 组合 | Ctrl+点击多选，Ctrl+G 组合，Ctrl+Shift+G 取消组合；也可用右侧按钮 |
| 家具尺寸 | 点击家具，在右侧输入宽／深／高 |
| 家具形状 | 右侧“家具形状”切换；“设为正圆”统一宽深；多边形顶点可拖动或输入坐标 |
| 3D 查看高度 | 默认显示完整高度及窗框；右上可切换“自动透明遮挡墙”“完整墙高”或“全部透明轮廓” |
| 平移 / 缩放 | H 或按住空格拖动；滚轮缩放 |
| 旋转 / 复制 | R；Ctrl+D |
| 撤销 / 重做 | Ctrl+Z；Ctrl+Shift+Z |
| 精细移动 | 方向键 1 cm，Shift+方向键 10 cm |

窄屏时属性面板位于画布下方。手机可用指针拖动，但复杂布局建议使用电脑或平板。3D 需要 WebGL；无法初始化时仍可使用 2D。

## 尺寸与几何约定

全部数据以 **cm** 表示。平面 X 向右、Y 向下；家具位置是中心点，rotation 为顺时针角度；elevation 为离地高度。3D 对应 X、Y 高度、Z 平面纵向。

房间顶点与墙体路径使用墙中心线，因此按尺寸创建的矩形是**中心线尺寸**，净空需扣两侧半墙厚。墙体与地面轮廓是独立对象：移动整间房会带上关联墙体，修改单面墙或地面顶点不会自动重建另一方。右侧“按轮廓重建墙体”会替换关联墙体并移除其门窗。

曲线是二次贝塞尔，不是圆弧约束；弧长和曲线碰撞使用采样近似。面积只统计地面多边形，重叠房间面积不会合并；曲线墙不会自动裁切地面。空间检查按家具轮廓计算，支持凹口；圆形和椭圆采用 64 段近似，不含柜门、椅子拉出或人体活动空间。测量标注固定在选定坐标上，移动家具不会自动改变标注。

自定义家具为等高拉伸体，暂不支持轮廓内孔或自由曲线边；不同高度的部件可分别创建后组合。编辑顶点后自动更新包围框中心与宽深，其余顶点的世界位置保持不变。选“原有家具模型”恢复 kind 对应的床、桌等简化模型。

组合支持嵌套；点击成员会选中最外层组合。取消组合后可编辑单个对象。选区中包含锁定家具时，整体移动和旋转会被阻止；房间与关联墙体一起移动，多选同一墙体不会重复位移。老版本无 `groups` 字段的 JSON 会自动兼容为空组合列表。

3D 用尺寸驱动的简化几何展示，不是施工 CAD；暂不支持楼层堆叠、自由曲面家具、物理模拟、3D 直接拖动家具或自动生成最优布局。可从 2D 或属性面板编辑，3D 即时预览。

## AI 接入

详见 [docs/AI_API.md](docs/AI_API.md)。不需要填写模型 API Key；本工具暴露操作能力，由外部 AI 客户端选择模型并调用。

### CLI

```powershell
npm run ai -- get
npm run ai -- analyze
npm run ai -- dry-run examples/commands.json
npm run ai -- apply examples/commands.json
npm run ai -- measure 0 0 30 40
```

### MCP

先启动 RoomView，然后在支持 MCP stdio 的客户端中添加 [examples/mcp-config.json](examples/mcp-config.json) 中的配置。将 `/absolute/path/to/RoomView` 替换成自己的项目绝对路径（Windows 可写为 `C:/projects/RoomView`）。桥接器使用 Node 内置模块，无额外依赖；实现 MCP 2025-06-18 初始化、工具发现与调用，可协商 2024-11-05 / 2025-03-26。

### 静态部署

将 `dist/` 放到任意静态服务器也能使用 2D/3D 与浏览器存储，使用 `window.roomview` 接入 AI。**HTTP API、磁盘保存与 MCP 需要 `server.mjs`**；纯静态模式没有这些服务。

## 数据与隐私

- 项目首次启动会创建程序内置的演示布局；仓库不携带个人房间方案。
- 本地服务将布局保存在 `data/project.json`，浏览器同时保留本地备份。纯静态部署只使用浏览器存储。
- 没有内置遥测、云端同步或第三方模型调用；安装依赖需要网络，应用构建后使用本地资源。
- `data/`、根目录导出的布局 JSON、测试截图、构建产物和环境配置均已加入 `.gitignore`。分享项目时仍需检查自己新增的文件。
- HTTP API 只监听回环地址并检查同源请求；没有公网账户鉴权，不要直接作为公开多用户服务暴露。
